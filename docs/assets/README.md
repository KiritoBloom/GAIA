# README banner

`gaia-banner.png` is the GitHub-ready banner. `gaia-banner.svg` is its editable composition, referencing the adjacent photograph and the project's Geist font.

## Photography

- **Credit:** NASA / Johnson Space Center.
- **Image:** ISS072-E-724819, *An atmospheric glow blankets Earth's horizon*.
- **Date:** 5 March 2025.
- **Context:** Pacific Ocean, photographed from the International Space Station.
- **Source record:** https://images.nasa.gov/details/iss072e724819
- **Downloaded image:** https://images-assets.nasa.gov/image/iss072e724819/iss072e724819~large.jpg
- **Use guidance:** https://www.nasa.gov/nasa-brand-center/images-and-media/

The composition crops and shades the photograph for readability. It is illustrative identity material, not a GAIA numerical artifact, a live acquisition result or a NASA endorsement. No NASA insignia is used.

## Typography

Geist, using the existing [`artifacts/fonts/Geist.ttf`](../../artifacts/fonts/Geist.ttf), distributed under the [SIL Open Font License](../../artifacts/fonts/OFL.txt).

The PNG was rasterized locally from the SVG with resvg-js, loading the font explicitly. No browser, running application or external image-generation service was used for rendering.

## Presentation imagery

The seven-page demo reuses the credited NASA horizon photograph and Geist. Its other diagrams are original illustrative graphics. The Central Interior outline is drawn from the actual retained BC government polygon in the [completed evidence archive](../submission/bc-central-interior-investigation.json.gz), displayed in geographic coordinates; it is not an invented study boundary.

`gaia-workspace.png` is a cropped screenshot of the actual completed Central Interior report in GAIA. It is not a fabricated interface or a new investigation. The sidebar is excluded. Fonts and images are embedded in the exported slide HTML.
