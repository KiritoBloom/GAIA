# GAIA's hexagonal identity

Original, self-contained SVG artwork with outlined lettering. No external fonts, raster images, scripts or network resources.

| File | Visual direction |
|---|---|
| `gaia.svg` | New planetary G shell, emerald Earth core and pale-gold evidence gate |
| `aura.svg` | Three freely tapering atmospheric ribbons |
| `thalassa.svg` | Water volume and a genuine negative-space circulation channel |
| `chloris.svg` | Canopy-green leaf planes and a champagne growth seam |
| `zoe.svg` | Winged-animal silhouette and a negative-space observation eye |
| `constellation.svg` | The exact five hexagonal marks integrated into one interwoven hexagonal seal |

Each function also has a `*-icon.svg` version without lettering or a full-canvas backdrop. Compact versions use optically strengthened hexagonal edges for small-size legibility. Each SVG has accessible title/description metadata.

All five frames are now hexagons, with matching six-sided construction, colored upper edges and inset secondary-color lower edges. Both the canvas and frame interiors are pure black. The symbols and individual palettes are retained. GAIA's earlier rejected five-petal mark remains replaced by the planetary G. The Earth core is symbolic artwork, not a geographic dataset or accurate projection.

Each function has its own coordinated palette, on the shared pure-black canvas `#000000`:

The combined artwork places GAIA center, AURA north, THALASSA east, CHLORIS south and ZOE west. Its outer boundary and central echoes are hexagonal. Unevenly spaced rounded loops, exact curved crossing bridges and colored coupling filaments preserve the intricate internal composition, clipped to the outer seal. Labels are spaced below the taller hexagonal frames. Every combined emblem reuses the exact standalone artwork, with namespaced IDs to avoid mask/reference collisions. These details are decorative identity art, not live agent status, progress values, sensor readings or evidence of scientific capability.

Reusable SVG groups: `emblem`, `field`, `symbol` and `wordmark`. These are designed for dark surfaces. Wordmarks are outlined from the locally installed Bahnschrift font; no font file is distributed and no font installation is required to open the artwork.

Design read: original scientific-agent identity overhaul, not a website build. Applicable principles from `design-taste-frontend` and `brandkit`: reference-independent concept, meaningful symbols, consistent shape language, function-specific coordinated palettes, restrained typography and inspected rendering. Design dials: variance 6, motion 1, standalone density 2, combined-seal density 6. Custom SVG marks are intentional because the user explicitly requested original SVG logos; no frontend dependencies, UI mockups or unrequested animations were added.

All 11 SVGs are checked for unique IDs, resolved internal references, self-contained vector content, six-sided frame paths and pure-black backgrounds. PNG previews are 1200 square for each function and 2400 square for the combined artwork; compact marks are visually inspected at 128, 64 and 32 pixels.

PNG files are viewing previews; SVG files are the scalable artwork. Rejected explorations are retained in `exploration-01/` and `exploration-02/`. The existing root `Logo.png` and `plan.md` are unchanged. These are identity concepts, not implemented agents or proof of scientific capabilities.
